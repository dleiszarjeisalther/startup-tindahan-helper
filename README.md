# Tindahan Helper

Modern, 100% offline-first Android Point-of-Sale (POS), Inventory & Utang Management system designed specifically for Filipino Sari-Sari Stores.

## Features
- **Offline-First SQLite**: Full POS checkout, barcode scanning, inventory tracking, and suki utang ledger without needing an internet connection.
- **7-Day Free Trial & Pro Licensing**: In-app onboarding with hardware-backed device fingerprinting and phone deduplication.
- **ESC/POS Bluetooth Printing**: Print 58mm/80mm thermal receipts directly to portable Bluetooth printers.
- **GCash & QR Ph Ready**: Built-in reference logging and payment verification.

## Development

```bash
# Install dependencies
npm install

# Start development server
npx expo start

# Typecheck & Lint
npx tsc --noEmit
npx expo lint
```
